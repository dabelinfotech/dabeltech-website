# DABELTECH — Leading The Digital Revolution
### Smart Solutions & Tech Institute Official Web Platform

Welcome to the official web repository for **DABELTECH** and **DABELTECH INSTITUTE** (Lagos, Nigeria & International Hubs in Ghana, Kenya, Cameroon).

---

## 🚀 Key Highlights & Platform Capabilities

- **Interactive Executive Dashboard:** Live cloud-dashboard simulation showcasing procurement analytics, school result portals, CBT systems, and the executive leadership desk.
- **Official Advert Video Showcase:** Auto-sequenced HTML5 cinema broadcasts with sound control and ambient backdrop illumination.
- **Motion Banner Slider Engine:** 19 interactive motion slides featuring comprehensive program flyers, certified cohorts, smart software services, and bootcamp admissions with zero image cropping (`object-fit: contain`).
- **Quick Select Any Banner:** Touch-optimized thumbnail preview carousel with horizontal sliding and flanking directional controls.
- **Academic & Career Programs:** 7 certified tracks spanning Data Analysis & Visualization, Full-Stack Engineering, AI & Machine Learning, Cybersecurity, Digital Marketing, and YouTube Monetization & Faceless Channels.
- **Smart Tech Services:** Turnkey ed-tech platforms, custom school result portals, computer CBT setups, and hardware diagnostics.
- **Multi-Currency Tuition Estimator:** Real-time fee conversion across NGN (₦), USD ($), GHC (₵), KSH (KSh), and CFA (FCFA).
- **Responsive Architecture:** Fully optimized across mobile devices (320px+), tablets, and high-DPI desktop screens with zero horizontal overflow.

---

## 🛠️ Technology Stack

- **Frontend:** Vanilla HTML5, CSS3 (Modern Glassmorphism & Micro-Animations), Vanilla JavaScript (ES6+ Modules)
- **Design System:** Inter, Plus Jakarta Sans, JetBrains Mono, FontAwesome 6 Pro Icons
- **Local Dev Server:** Node.js HTTP static server on port 8080

## ⚡ Quick Start

```bash
# Clone the repository
git clone https://github.com/dabelinfotech/dabeltech-website.git

# Navigate to project directory
cd dabeltech-website

# Launch development server
node server.js
```

Open `http://localhost:8080` in your browser.
